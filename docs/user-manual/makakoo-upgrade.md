# `makakoo upgrade` — legacy alias for `makakoo update`

`makakoo upgrade` still works for old scripts and old runbooks. New docs and UI should say `makakoo update`.

For the full flag reference, read [`makakoo-update.md`](makakoo-update.md).

```bash
makakoo update
makakoo update --dry-run
makakoo update --reinfect
makakoo upgrade    # legacy alias
```
